# 参数起点、方向与结果判断

## 怎么使用这张表

以下数值是**美术试调建议**，不是 lilToon 官方预设，也不是已替任意头像验证的配置。仅在当前 Shader 的类型、Range、混合方式与这里一致、用户没有指定数值时采用；已有正确配置和用户选择优先。先从实际值附近小步改，保留正常端点。不同 UV 尺度、灯光、纹理和 Shader 会改变视觉结果。

属性名是 lilToon 的可辨识示例，不是跨 Shader 映射表；先在当前 Shader/材质返回中确认，不能按名字强行创建。所有选配项只在当前问题需要时调整，不一次写完整张表。

## 表面和部位

| 目标／先读条件 | 可选试调起点 | 增大／减小会怎样 | 看什么；不对时怎么改 |
| --- | --- | --- | --- |
| 主色：底图和第二/第三颜色层；颜色是否被贴图乘算 | 用户色；若用户要淡蓝可使用其指定色，不能擅自沿用上个模型的蓝色 | 亮度提高更浅；饱和度提高更鲜艳；深色底图仍可能把它乘暗 | 身体/脖子/胸下色调连续，眼睛口腔不误染；残留肉色先查其它颜色层，别无限加饱和度 |
| 身体最终 alpha：普通透明、无替换 mask 覆盖、数值0–1 | 约0.55，小步±0.05；原模型已有目标外观则沿用 | 更大更不透明、轮廓更厚；更小内部轮廓更清楚，但可能失去体积 | 用穿入测试物看轮廓，并看斜侧；alpha=0不代表保留高光/外壳，不能以完全消失当成功 |
| 头部最终 alpha：脸外壳与眼口/备用片已区分 | 约0.8，通常高于身体；先保留眼睫自己的值 | 降低更透，也更易暴露口腔/备用片；提高改善遮蔽但削弱透过 | idle与使用中的表情、后脑都看；不把提高到1当作透明头部验收，也不全脸共用身体alpha |
| 头发、耳、尾 alpha：有发丝/尾尖轮廓 mask | 先保留轮廓，胶体实体区可从0.7–0.85附近比较 | 降低更通透且透明重叠更明显；提高发束更实但可能盖住五官 | 背景不能变矩形白片；孔洞保持孔洞，保留纹理alpha而不是用均匀值填满 |
| Alpha Mask：当前替换/乘算及其 Scale/Offset | 保留现有模式；仅为本次目标编辑对应区域/强度 | 替换会改最终alpha来源；乘算会与原alpha相乘；Offset改变可能使整片区域饱和 | 颜色alpha改了无效先查mask与动画；局部mask用于该材质内部，不代替跨材质Stencil |
| 皮肤额外颜色层，如已启用的 `_Color2nd` | 保留其RGB，按用途调整alpha；正常端点为读回原值 | 减少确认为肤色overlay的贡献可去肉色；误减表情层会损坏脸 | 仅动画支持该字段时写完整RGBA；不支持的静态raw Color写入应报缺口，不能塞入scalar接口 |

## 光泽和波纹

先启用当前 Shader 对应功能，再调强度；不存在的属性不写。粗糙度与 Smoothness 方向相反，不能混用。

| 目标／lilToon示例 | 可选试调起点 | 增大／减小会怎样 | 看什么；不对时怎么改 |
| --- | --- | --- | --- |
| 光滑度 `_Smoothness`，Range0–1 | 约0.75，步长0.05 | 更大高光更锐、反射更清晰；更小更宽柔 | 高光不白成整片、近看不闪；太锐先降光滑度，不靠增大发光补光泽 |
| 金属度 `_Metallic`，Range0–1 | 水/胶体取0附近；不是所有 Slime 都要金属 | 更大会更像导体，改变底色与反射关系；更小保留介质感 | 蓝色像镀铬时先降金属度；不改正常金属饰品 |
| 反射率 `_Reflectance`，Range0–1 | 当前非金属配置；可从0.04附近比较，步长约0.01–0.02 | 更大反射更显眼；更小更克制 | 结合灯光/环境看；太亮先降反射贡献，而不是让整个身体消失 |
| 法线开关/强度 `_UseBump2ndMap`、`_Bump2ndScale` 等 | 已确认普通强度语义时，开关启用，强度约0.2，步长0.1；保留原第一法线 | 正强度变大水波更鼓、反光更碎；接近0更平；负值可能反转凹凸，不是“更弱” | 光照/高光应响应法线；没有效果先查开关、槽位和光泽，脸扭曲先降强度 |
| 波纹 Tiling，纹理变换xy | 无既有值时从(2,2)看；对身体和发束分别比较 | 更大纹理重复更多、波纹更细密；更小更粗大；0会压成单一采样 | 接缝与头发高光是否过碎；UV岛密度不同就分别调整，不强制所有部位相同 |
| 独立波纹 Offset，纹理变换zw | 从已知Offset起；平铺纹理可先用一个轴每8–20秒移动1个周期 | 同一周期位移下时间更短＝速度更快；位移反号＝方向反转 | 多时刻有运动、跨周期不跳；先匀速循环，不对主图/面部遮罩应用这条动画 |
| 边缘光／Fresnel，例如 `_RimFresnelPower` | 优先沿用原配置；需要边缘感才启用并低强度比较 | 经典Fresnel指数更大通常集中在更薄的边缘；具体Border/混合会改变结果 | 边缘加强体积但不画出厚白描边；与环境及肤色一起看，不把它当透明度 |
| 真折射（选配） | 普通透明能满足就保持不用；用户确需扭曲时从0强度小步增加 | 强度更大背景越扭曲；模糊/多pass通常增加成本 | 测试物仍可辨、双眼/镜子不异常；先撤不必要折射，不用它掩盖内部表情 |

## 深度、排序、镜片

这些值不是审美滑块，数字增减不等于“效果更强”；先查枚举与作者的 pass/Stencil 关系。

| 设置 | 起点、方向、适用范围 | 结果与纠错 |
| --- | --- | --- |
| Render Queue | 沿用作者正常配置/已通过的 Slime 配置；数值更大通常更晚画。-1用Shader默认，不参与大小排序 | 有确定相对顺序冲突时才把有关层排到目标之前/之后；不要把所有透明材质都设成最大值 |
| ZWrite | 沿用当前透明模式；0/1是关/开，不是透明度。仅在已定位的深度缺陷上比较 | 开启可能遮住后画内部物体；头部预写只应用于需要的表面。内部片消失但测试手臂也看不见，仍失败 |
| ZTest / Cull / Stencil | 保留作者关系；按实际枚举选择，不把数值当强度。双面会增加绘制且可能暴露内面；Stencil Ref是标识 | 关闭深度比较不能作为通用修复；改变Stencil前查所有读写层，不能乱占固定ID。FakeShadow按脸/头发/投影的配套关系处理 |
| 镜片（仅它确实遮挡Slime脸时） | 独立工作材质保留镜框；无需折射时先普通透明，原alpha附近逐步降低遮挡，轻反射 | 看眼睛/刘海与侧面，不只看正面；先区分反光和深度，镜片方案不套到身体和虹膜 |

## 过渡、运行检查与恢复

| 项目 | 起点与调整方向 | 怎样确认 |
| --- | --- | --- |
| 变身时长 | 用户要求/现有值优先；没有要求可从约1秒试调。缩短更利落、加长更舒缓 | 观察首尾和中段，不能只读clip长度；材质引用交接点与曲线要连续 |
| RGBA和XYZW端点 | 来自正常/Slime实际目标；曲线中未改变分量也明确写全 | RGB清零发黑、ST.xy清零不出波纹都是已遇到的风险；逐分量读存档，再采样实际运行值 |
| 反向与中断 | 保留/选择当前Animator真正支持的双向过渡和中断，不猜API字段 | 半途反向从当前效果返回；不闪黑、UV不归零，正常端点材质和颜色完整恢复 |
| 默认与同步 | 新开关默认正常；saved/synced按已确认意图设置 | 本地菜单变化不等于好友已看到；客户端同步单独报告，不靠增加无关参数解决 |
| 保存与性能 | 只保存本次资产/场景；对正常/Slime采用同光照与视角比较 | source资产成功、动画存档成功、运行画面通过分别报告；小贴图不等于透明层数/overdraw成本低 |

调完目标部位即可继续，不要求跑完每行；已知正确项不重复核查。发现独立衣柜、体型、物理或工具实现问题另报，不纳入 Slime 调参。
