# VRCForge 1.8.2

这次更新集中改善内置 AI 的工具选择、结果读取和任务收尾，并完善记忆审批、停止取消与聊天界面。Agent 能按需加载具体工具，减少重复调用，也能更完整地利用已经读取的结果。

## Agent 工具与任务执行

- 基础文件读取和网页读取更容易被发现、选用；读取网页时优先使用专用读取工具，减少不必要的 Shell 调用。
- 工具块支持按名称只加载下一步需要的工具，重复的参数说明统一展示，减少每轮请求携带的内容；仍可发现完整工具目录。
- 保留工具结果中的关键字段、准确路径和续读信息。长文件与截断结果可以继续读取，避免为了查看尾部重新执行原工具。
- 检查当前 Unity 场景、组件绑定或 Avatar 行为时，优先使用相应的检查工具，避免把找到的文件名误当成当前使用的资源。
- 连续工具错误会触发循环保护；遇到明确的工程范围拒绝时停止并给出切换会话的提示，不再反复换路径或工具尝试。
- 同一结果的读取错误被成功修正后，旧错误不再覆盖最终答复。模型返回无法解析的 JSON 时，最多请求一次格式修正，不重跑已执行的工具；仍然失败则明确显示失败状态。

## 记忆与反思

- 支持通过实际工具保存“记住这件事”的请求，并以保存回执确认结果；可以查看、召回和删除已保存的记忆。
- 普通对话记忆继续自动保存，项目记忆按工程范围使用；改善同一轮明确保存与自动保存的重复处理。
- 反思与 Dreaming 生成的修改先作为待审建议，批准后才生效；拒绝不会修改记忆，过期建议不能覆盖较新的内容。
- 手动反思前显示实际服务商、模型和付费调用提示。关闭记忆会取消后台处理，并在写入前再次检查启用状态。
- 拦截可识别的密钥等敏感内容进入记忆，并在读取和模型上下文中加强脱敏。

## 聊天界面

- 进度说明与工具结果分开显示，工具详情收进可展开卡片，减少重复旁白。
- 保留最终答复的段落与列表格式，修复部分任务事件导致聊天保存失败的问题。
- 子 Agent 的进度和入口保留在右侧栏，避免在主对话重复显示。
- 显示工具或模型的最终失败状态，并提供记忆建议的批准、拒绝入口。

## 实测示例

以下是不同场景各自的前后对比；耗时和用量还会受任务、工程规模、模型与网络影响。

| 场景 | 本轮实测变化 |
| --- | --- |
| 读取一个指定网页 | 耗时从 60.31 秒降至 14.61 秒，减少约 **76%**。 |
| 一次文件读取任务 | 工具调用从 3 次降至 1 次，减少约 **67%**；更新后耗时 9.24 秒。 |
| 同一个真实 Unity 工程中的只读检查任务 | 模型用量从 238,560 tokens 降至 116,779 tokens，减少约 **51%**；耗时从 96.46 秒降至 66.05 秒，减少约 **32%**。 |

Unity 数据来自同一工程、同一任务的单次前后对比，仅代表该实测样例。文件和网页是另外两个场景，不能将这些比例相加，也不代表所有工程或任务都会获得相同提升。

## 下载与升级

- **Offline Installer**：完整安装包，适合直接安装。
- **Web Installer**：小体积安装器，安装时下载本版本程序。
- **Windows x64 ZIP**：完整程序文件。
- **VRCForge.unitypackage**：Unity 插件。
- **release-manifest.json**：文件版本与校验信息。

App 版本为 1.8.2；Unity Core 保持 1.8.0。已经正常连接的工程无需为本次 App 更新重新导入 Core。安装时若程序仍在运行，按提示关闭后点击重试。
