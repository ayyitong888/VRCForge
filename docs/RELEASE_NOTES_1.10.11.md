# VRCForge 1.10.11

## 对话与审批

- 任务栏按未读对话、待答问题和待审批请求计数。打开对应对话只清除该对话的未读计数。
- 点击右栏的待查看提醒，可跳到对应对话并展开问题卡。浏览器确认问题显示在发起它的回合旁。
- 外部 MCP 操作需要人工批准时，会在 App 工作区显示审批卡；设置页不再弹出审批。完全权限仍按现有设置处理。
- 折叠的工作记录只保留用时，展开后可查看工具详情。排队消息在对应回合结束后发送，实际接收后才进入对话。

## Agent 与 Unity 工具

- 子任务用尽预算时可继续原会话，并返回已取得的证据。父回合等待子任务时不再显示为待用户处理，自动压缩也会出现在时间线上。
- 修正子任务的工程和会话范围、重复续接、停止和报告交付。
- 改进材质叠层、组件属性及外部 MCP 的工具查找指引，减少材质扫描续读的重复计算。
- 阻止明确会删除或搬走整个工程、覆盖关键文件的 Agent Shell 命令。
