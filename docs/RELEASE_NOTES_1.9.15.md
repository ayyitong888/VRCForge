# VRCForge 1.9.15

VRCForge 1.9.15 汇总了自上次公开版本 v1.9.6 以来的累计改动，涵盖 Agent 对话、人工反馈、侧栏恢复、通知和 Unity 头像工作流，并提供 Windows x64 安装包、便携版与 Unity Core 包。

## 对话与 Agent 工作流

- 改进上下文压缩与续跑：按会话窗口建立压缩输入，保留完整历史恢复依据；修正分页上限和重复压缩等问题。真实长对话完成压缩并续跑成功；预算仍是估算，校准样本不足时不能视为精确 token 预测。
- 普通提问和视觉检查问题可在聊天内用紧凑的单行输入回复，也可跳过；问题卡保持聊天上下文可见。反馈状态与权威回合元数据会随会话保存和恢复。
- 修复反馈和运行状态与聊天/回合的归属，避免新聊天显示其他会话的问题、把旧问题重复派发，或让流式等待状态跑到聊天历史顶部。
- 改进审批续跑的持久化和恢复，使审批队列繁忙或进程重启时仍能保留待继续的事务上下文。
- 修正共享 Unity 工具链的对象身份与检查点范围处理，改善精确场景保存、Prefab 解包和衣柜操作；合法的 opaque 引用不再被凭据脱敏规则误拦截。
- 改进 Modular Avatar 对已有组件的更新，避免重复创建组件；修正纹理字节快照读取，并按衣装关联身体形态与动画。
- 修正审批上下文重复存储及 set JSON 序列化问题，提升审批续跑数据的完整性。
- 改进 ReAct 回合结束处理，移除自然完成后仅为补写完成标记而重复请求模型确认的步骤。

## 聊天界面、侧栏与通知

- 侧栏聊天列表可快速恢复显示，并支持会话/项目排序和拖动顺序持久化；启动缓存只用于列表展示，后续由权威数据更新。
- 显示用户与 Agent 消息时间、日期分隔和处理时长；运行中的等待提示跟随其所属回合，日期分隔位于对应用户消息之前。
- 提供问题、审批、复核和目标等事件的通知音效配置与重试去重；保留 Windows 通知集成。
- 改进聊天编辑器、问题卡和工作区布局，并更新多语言界面资源。

## Skills 与工作流指南

- 更新内置 avatar Skills 与配套工作流，明确衣柜、动画、面捕安装、头部移植等路径的适用边界、检查步骤和工具选择。
- 新增 VRCForge Docs、首次运行和面捕安装指南的源内容，并调整内置 Skills 注册与分发实现。
- **发行包边界：** Skills 1.1.24 仅在隔离测试 profile 中确认；不能据此声称该版本已安装在本次发行包中。发行包的 Skills 版本以实际载荷为准。
