# VRCForge 1.11.0

## 对话与模型

- 可在任务运行中或等待审批、回答时切换模型和推理强度。下一次模型请求使用新设置，已发出的请求继续使用原设置。
- 设置按用途分组。聊天设置新增默认关闭的输入预测。开启后可用 Tab 接受灰字建议，编辑后再发送。
- 对话按事件发生时间显示提问与回答，并将同批启动的子智能体合并显示。

## 长任务与恢复

- 上下文压缩保留用户原话、任务依赖和工具回执。主智能体和子智能体都可沿已记录的进度继续。
- 素材扫描、导入预检与审批恢复可以引用之前的回执，区分已找到的素材、未读完的包和已经完成的操作。
- 改进 Unity 连接与工具状态的反馈，方便核对等待、执行和恢复进度。
