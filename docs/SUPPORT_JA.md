# VRCForge サポート案内

## 困ったとき

1. Doctor を開き、表示された内容を確認します。
2. Doctor または設定の「サポートバンドル」を書き出します。
3. 「最新バンドルを確認」で、含まれるファイル名と匿名化済みの内容を確認します。
4. フィードバック欄に、起きたことと再現手順を短く入力し、「匿名化プレビューを作成」を押します。
5. プレビューとバンドルを自分で確認してから、必要なら「プレビューをコピー」で GitHub のフィードバックページへ貼り付けます。バンドルの添付も手動で行います。

フィードバックページを開くだけでは、内容は送信されません。VRCForge は自動アップロードを行わず、ページを開く動作と実際の送信・添付の許可を分けています。

長いファイルは一部だけ表示されます。「省略」の表示がある場合は、共有する前に書き出した ZIP 内のファイルも確認してください。プレビューを開くだけでは「確認済み」にはなりません。確認が終わってからチェックを入れ、表示されたファイル名のバンドルを添付してください。

## 公式サポートの範囲

VRCForge の公式サポート対象は、VRCForge App、VRCForge Unity Core への接続、プロバイダ設定、VRCForge で再現できるエラーです。Unity や VRChat の第三者アセットそのもの、購入済みコンテンツ、外部サービスの障害、任意のモデル回答の正しさは対象外です。

## 個人情報とファイル

ログとサポートバンドルは、保存前にキー、トークン、個人用パス、プロジェクトや Avatar の識別情報を匿名化します。ただし、共有前にプレビューを確認してください。API キー、Gateway トークン、購入済みアセット、私有ファイル、不要なスクリーンショットは貼り付けないでください。

サポートバンドルは、ユーザーが確認したものだけを手動で添付します。VRCForge が GitHub issue に自動添付することはありません。
