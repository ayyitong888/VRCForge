# VRCForge 1.8.6

本次更新修复 Agent 工具循环、审批续接和聊天显示，并统一连接状态判断。

## 任务执行

- 支持模型原生工具调用，保留调用与结果的对应关系、供应商状态和思考字段，减少重复上下文。
- 修复工具发现、参数检查、错误恢复和完成判断中的问题，避免旧错误覆盖已经完成的答复。
- 审批、问题回答、停止和续接绑定所属会话，修复审批出现在其他会话或页面的问题。
- 自动审批使用独立模型调用审查请求；无法确认时仍交给用户批准。
- 临时通信超时后可继续接收同一任务的结果，不重新发送请求或重复执行。

## 聊天界面

- 按顺序显示过程说明与工具调用；连续调用合并展示，展开时减少重复层级和缩进。
- 修复历史工具详情无法展开、回复重复或消失，以及运行计时更新不及时的问题。
- 等待用户回答时显示完整问题、选项和可输入的其他回答，隐藏普通聊天输入框。
- 侧栏运行中显示转圈；后台完成后显示主题色未读圆点，进入会话后清除，刷新后保留已读状态。

## 连接与工具包

- 引导、设置、体检和诊断共用连接与配置状态，正确识别插件编译失败和配置完成状态。
- 用户安装的工具与官方工具分别管理，官方更新保留用户工具，并检查工具包兼容性。
- 修复用户工具调用结果和失败状态传递，保留审批、检查点及读回验证流程。

## 下载

- **Offline Installer**：完整安装包。
- **Web Installer**：安装时下载本版本程序。
- **Windows x64 ZIP**：完整程序文件。
- **VRCForge.unitypackage**：配套 Unity 插件。
- **release-manifest.json**：版本与文件校验信息。

App 版本为 1.8.6，Unity Core 编译版本维持 1.8.0，工具契约为 160，包含 97 个声明工具。升级时请使用本版本配套的 Unity 插件。

复杂任务的工具选择仍取决于所用模型，本版本不保证所有项目故障都能自动修复。
