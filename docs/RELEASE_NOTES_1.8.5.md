# VRCForge 1.8.5

本次更新改善任务执行、回复显示和首次配置体验。

## 任务执行与回复

- 同一轮的工具调用和过程说明统一折叠，最终答复单独显示；修复流式回复重复出现或显示后消失的问题。
- 长工具结果明确标记省略范围并保留续读信息，帮助 AI 区分已确认结果与尚未确定的候选结果。
- 修复长任务的上下文预算检查遗漏；格式不完整的任务响应可进行一次有界纠正。
- 停止操作绑定当前任务，并联动所属子任务；修复停止信号影响下一轮和事件归属错误的问题。
- 补齐断线后已完成答复的恢复，避免为了恢复显示而重新执行任务。
- 修复普通文件写入错误依赖 Unity 检查点的问题，保留现有权限与批准流程。

## 首次使用与设置

- 进入 AI、外部客户端或项目设置后保留引导进度，返回时可以继续。
- AI 配置提供逐步高亮说明，包含填写凭据、拉取模型、选择模型、保存和测试；验证成功后返回引导。
- 区分“配置已保存”和“连接已验证”，并补充 Unity 插件导入的菜单路径和操作步骤。
- 修复测试连接时界面可能无响应，以及滚动或布局变化后引导高亮偏移的问题。

## 外部 AI 连接

- 改善 Windows 上 Codex App 的安装检测，并明确提示 Gateway 未开启的情况。
- 使用同一用户配置的不同 VRCForge 版本可复用现有 MCP 启动入口，不因程序路径不同而要求重新安装。
- 对真正独立的配置保留冲突提示，防止意外覆盖或移除另一份 MCP 绑定。

## 下载

- **Offline Installer**：完整安装包。
- **Web Installer**：安装时下载本版本程序。
- **Windows x64 ZIP**：完整程序文件。
- **VRCForge.unitypackage**：配套 Unity 插件。
- **release-manifest.json**：版本与文件校验信息。

App 版本为 1.8.5，Unity Core 编译版本维持 1.8.0。

Protocol: MCP 2.0 (`2026-07-28`). Windows binaries are not code-signed; verify the release manifest hashes.
