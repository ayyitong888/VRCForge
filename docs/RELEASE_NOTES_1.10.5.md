# VRCForge 1.10.5

**App、Backend 和安装器更新。Unity Core 保持 196，沿用 1.10.4 的插件包；已安装 Core 196 的工程无需重新导入。**

## 修复

- 修复 Windows 连接重置后服务无法继续接收请求的问题。
- 并发聊天更新冲突时重新同步；删除持久记录失败时保留聊天和运行历史，持久删除后运行历史清理失败会如实显示部分成功。
- 同一对话的运行请求按序处理；子任务完成后续跑不会覆盖仍在执行的工具回执。
- 停止任务和队列操作保持界面与本地服务响应；删除仍在运行的会话时先停止运行，并清理归档正文。
- 异常结束后清除旧流式会话上下文，避免影响后续工作。
