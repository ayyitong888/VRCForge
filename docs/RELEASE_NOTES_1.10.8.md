# VRCForge 1.10.8

本次同时更新 Windows App 和 Unity Core。已连接的 Unity 工程请导入本次发布的 `VRCForge.unitypackage`。

## 主要修复

- 内置 Agent 的自动审批会先交给独立审查模型检查命令，再决定是否执行。可用时优先使用轻量审查模型。审查拒绝或无法给出有效结论时，命令不会执行。
- 修复附件拖放可能重复提交并报上传数量超限的问题。委派给子 Agent 时，保留当前任务已授权的读取范围。
- FBX 检查点会区分可保存的改动和 Unity 导入生成的子对象，并在保存回执中指出需要处理的对象。导入回执保留失败阶段、错误码和任务标识；导入后会检查 FBX 是否有可用的网格和渲染器。
- 改善回复截断后的恢复、上下文用量显示，以及运行错误与具体操作的对应关系。

内置 Agent 仍在测试。遇到问题可提交 [GitHub Issue](https://github.com/ayyitong888/VRCForge/issues)。外部 MCP 接入已可正常使用。
