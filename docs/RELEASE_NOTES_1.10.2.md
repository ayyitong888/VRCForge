# VRCForge 1.10.2

**升级需要同时更新 App 和 Unity Core。** 下载 [Windows 安装包](https://github.com/ayyitong888/VRCForge/releases/download/v1.10.2/VRCForge_Offline_Installer_x64.exe)，并在要连接的 Unity 工程中完整导入 [VRCForge.unitypackage](https://github.com/ayyitong888/VRCForge/releases/download/v1.10.2/VRCForge.unitypackage)。

## Unity 与 Agent

- 新增单资产预览和保存工具：只保存指定资产；资产不存在明确报错，未修改的资产返回无变化。内置 Agent 与外部 MCP 使用同一入口。
- 修复菜单编辑重复标脏，避免保存子菜单时把未修改的根菜单留为脏状态。
- 已完成的场景写入沿用 Core 保存与读回事实，避免外层回执误报失败；写前准备保留具体失败原因。
- 修复 MA 嵌套材质引用的读回比较，以及只读材质影响报告对 package 场景路径的误拒。
- 工具描述明确参数、专用入口、纠正方式及动画中 Shader 分量的保留方法，减少为调用工具而阅读源码的需要。
- 普通目标读取不再计算整场景摘要；场景内容摘要和时间戳不再充当目标身份。材质批量工具按场景身份与实际槽位状态判断，保留写入读回和既有备份完整性检查。

## 会话与界面

- 修复复用客户端轮次 ID 时，中断任务被旧完成记录遮住的问题。
- 原生 PNG 截图可进入视觉附件链；场景另存为在父目录缺失时于写入前明确拒绝。
- 顶栏与工作区共用背景并显示版本号，修复可用高度和设置页标题残留；先绘制启动骨架，再加载应用依赖。
- 对话刻度预览过滤内部失败回执并支持 Markdown 显示；移除聊天附件的“导入到项目”功能。
- 本机日志与工具结果保留原始路径和续读参数，导出日志与支持包时脱敏。

## 验证范围与已知问题

- 已验证范围包括定向回放和指定真实 Unity 工程的相关工具调用；源码回放、测试版部署与正式安装包验收分别记录，不代表全部工具、模型或插件组合均已验收。
- 启动首绘仍未达到 100ms 目标；悬浮预览压平换行时仍可能破坏 Markdown 排版。这两项保留为后续修复。
- 工具间等待时间留待新一轮 benchmark 测量；不将历史日志中的等待直接归因于 Unity。
