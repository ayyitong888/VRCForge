# VRCForge 1.11.1

## 对话与输入

- 输入预测可单独选择模型和推理强度，默认跟随对话模型。建议按对话和轮次保存，切换对话、打开设置或重新启动后可以继续使用。
- 问题和批准请求集中在右上角「待处理」。点开可跳转到对应对话，问题卡显示在输入框上方。模型的执行计划保留在「待办」。
- 图片、附件和引用按添加顺序显示在文字输入上方。修复了 Windows 拖动窗口缩放后拼音候选框偏离输入光标的问题。

## 长任务与 Unity

- 智能体会等待正在执行的工具操作并核对结果，改进了 Unity 启动、插件连接和编译后的状态判断。
- 待办完成状态根据工具执行回执更新。上下文压缩后仍占用较多空间时，界面会建议新开对话。压缩后仍达到自动压缩线的对话会进入只读状态。
