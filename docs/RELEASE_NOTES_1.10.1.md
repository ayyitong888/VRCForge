# VRCForge 1.10.1

## 对话与界面

- 子智能体侧栏可以打开工作对话、查看历史并带上下文续问。
- 对话位置刻度支持悬浮预览和长列表滚轮滚动；预览的回复区域只显示 Agent 正文，不混入工具清单或取消状态。
- 检查点保留数量可配置，默认保留 4 个。

## Agent、MCP 与 Unity

- 工具失败返回具体字段、原始原因和纠正提示，内部 Agent 与外部 MCP 共用修复。
- MA、VRCFury 配置引导到专用入口；修复嵌套材质等类型引用转换。
- 动画写入按明确的 Animator 根检查绑定目标，缺失对象和失败的批量读取明确报错。
- UnityPackage 导入核对完整文件清单与实际落盘结果，缺文件不会误报成功；支持原生导出包的目录与路径格式。
- 修复已验证、已保存的 Core 写入被外层回执误报失败的问题，正确区分实际修改与无变化。
- 刷新和导入继续观察原任务，减少窗口探测故障造成的轮询中断。
- 减少重复身份取证、场景读取和图片解码，移除结构化列表兼容中的固定程序集摘要门槛。

## 发行内容与已知问题

- 提供 Windows x64 离线安装包、在线安装包、便携包及配套 Unity Core。
- 优化页面卡住、部分中断会话恢复和内置桌面截图兼容问题已登记，后续版本处理。
- 本版本的 Unity 实测覆盖指定工具及工程，不代表全部工具或所有模型效果均已验收。
