# VRCForge 1.10.0

## Agent 与 MCP

- 子代理拥有独立的模型上下文，支持声明式角色和带上下文续问，沿用现有 provider 配置。
- 修复外部 MCP compact 响应与 outputSchema 不一致，改善严格校验客户端的数据接收。
- Checkpoints 默认为开启；用户明确关闭后，在当前运行中的会话持续关闭，明确开启后恢复。内部 Agent 和外部 MCP 均支持。后端重启或新建会话恢复默认开启。
- 跳过 checkpoint 的写入会显示无还原点并保留引用记录；普通写入审批、原子写入和对象身份检查仍生效。
- 改善工具结果恢复、取消处理与会话续接，减少重复身份计算和日志快照复制。

## Unity 与界面

- NDMF 错误读取采用最后保留的构建报告，避免历史错误与当前结果混淆。
- 启动时先显示轻量界面和加载反馈，改善等待期间的可见状态。
- 更新 Avatar Skills，在功能不确定、用户纠正和错误原因不明时查阅对应版本的成熟实现。

## 发行内容与边界

- Windows x64 离线安装包、在线安装包、便携包及配套 Unity Core。
- 安装包与配套 Core 由本次发布标签对应的源码构建；文件 SHA-256 以附带的 release-manifest.json 为准。
- 会话 checkpoint 开关目前保存在内存中，不跨后端重启保存。外部指令引用由宿主 Agent 提供，不表示后端独立验证过宿主聊天记录。
- 不宣称所有历史问题均已关闭：完整 App 冷启动耗时及历史工具批次间等待仍需按实际场景继续测量。
