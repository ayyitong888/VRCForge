# VRCForge 1.10.14

## 对话与停止

- 点击停止后立即停止派发新工具调用，输入框无需等待 Unity 中已发出的操作结束。已发出的写入会提示读回确认。

## Unity 与 MCP

- 写入响应丢失时，同一会话可查原操作回执。会话变更后会提示先读回 Unity 现场，避免重复写入。
- 回滚确认后，临时资产不存在会按预期结果记录。写入回执直接提供对应检查点，工具预检拒绝的结果也会如实记入运行账本。
- 修正 Unity 资源路径比较，减少复制、迁移和预检中对同一路径的误判。
- 统一 Unity Core 的 MCP 参数与版本错误。HTTP 请求头与正文不一致时保留原请求 ID，STDIO 自动协商会忽略协议选定前的无 ID 通知。
