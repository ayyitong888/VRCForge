# VRCForge 1.10.7

**更新 App。Unity Core 继续使用 1.10.4 / contract 196，已安装的 Core 无需重新导入。**

## 修复

- 启动时先读取磁盘项目快照；快照过期后在后台更新，不再让启动扫描长时间占用左侧刷新按钮。
- 保留磁盘快照的原有有效期，短时间重开 App 不重复扫描；手动刷新与正在执行的后台扫描共用结果。
- 启动恢复复用同一遍账本读取的 Shell 状态，子 agent 状态在取得运行时所有权后加载一次，减少大历史记录下的重复读取。

必要的运行恢复仍在服务就绪前完成，聊天保存、权限和 Unity 调用流程保持不变。
