# VRCForge 1.10.12

## 启动与界面

- 新增可在通用设置中关闭的启动动画。运行时较早就绪时会加快剩余线稿，进入上色后会正常播完。
- 启动较慢时会显示当前步骤。超时或运行时进程退出时，会显示诊断摘要并提供重试。
- 修正设置页开关圆点的对齐，并简化技能导入界面。可以从导入界面直接打开技能管理。

## 对话与审批

- 各对话独立保存输入框草稿。编辑消息时可按 Enter 发送，停止 Agent 时会停止流式回复和尚未派发的工具。
- 改进聊天保存和重试恢复。消息发送回执丢失时可与已保存的记录核对，工具截图保持在原请求位置。
- 已回答的问题会从任务提醒中清除。历史记录会把问题与答案一起显示，Telegram 回答也会关联到对应会话。
- 改进自动审批结果的提示。完全权限下允许自动执行的请求直接进入已批准状态。

## Unity 与头像工具

- 导入头像贴图时会在适用的贴图上启用并验证 mipmap 串流。
- 编辑现有 FX 状态时，省略 Write Defaults 设置会保留原值。新状态沿用控制器的约定，并检查关闭 Write Defaults 时的空 Motion。
- 改进衣柜技能的换装核对，包含原头像的小件服装、套装切换和原装恢复。
- 内置头像技能增加作者署名，并减少 Unity 连接检查对运行时响应的影响。
