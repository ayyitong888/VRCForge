# VRCForge 1.10.13

## 对话与启动

- 修复编辑消息重跑后停止按钮可能找不到当前回合的问题。发送、停止、队列和续跑使用同一套会话与回合标识。
- 改进停止响应和上下文用量统计。主动停止时，压缩取消与压缩失败分别显示。
- 消息编辑改用文字按钮。启动动画铺满窗口，并清理画面上的残留文字。

## Unity 与 MCP

- Unity Core 写入回执保存在项目内。完整退出并重开编辑器后，仍可用原执行 ID 查询，不再按时间过期。掉线时按原操作查回执，避免重复提交写入。
- 工具参数错误会指出具体字段、允许值和可执行的修正方法。目标引用失效时会提供同项目的重新发现和绑定指引。
- 改进中英文工具搜索和工具加载指引，统一新版 STDIO 与 HTTP 的工具错误呈现。
- 改进材质槽和 FX Write Defaults 的读取。修复一处 UnityPackage 元数据换行，保留原 GUID。
