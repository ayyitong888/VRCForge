# VRCForge 1.8.4

本次更新修正新手引导的 Core 连接误判，并集中维护 Core 配置校验、请求鉴权和工具触发说明。

## 连接与新手引导

- 修复 Core 已健康连接、后端跳过重复工具枚举时，新手引导仍显示未连接的问题（#2）。
- 移除固定的 68 个工具总数，以后端版本、实例、执行就绪和必需工具检查结果判断连接状态。
- 后端明确报告执行未就绪、版本或实例不匹配、缺少必需工具时，仍保留失败提示。

## 工具调用

- 工具被选到错误分组时，返回当前可见目录中的正确归属，并允许模型进行一次纠正。
- 正确分组和完整工具集合加载成功后，原加载失败不再阻止任务完成。
- 重复错误会停止；无关成功、部分工具修正或缺少 Unity 上下文均不会解除原失败或扩大权限。

## 配置与维护

- Core 项目配置和每次请求的 Bearer 鉴权使用共用模块；正常调用与诊断探测保留各自的协议检查要求。
- 新建连接重新读取所选工程的配置，保留本机地址、项目绑定和凭证校验。
- Gateway 与 Planner 共用工具触发说明生成逻辑，减少重复维护，保留使用条件、禁止使用条件和反例。

## 下载与升级

- **Offline Installer**：完整安装包。
- **Web Installer**：安装时下载本版本程序。
- **Windows x64 ZIP**：完整程序文件。
- **VRCForge.unitypackage**：配套 Unity 插件。
- **release-manifest.json**：版本与文件校验信息。

App 版本为 1.8.4，Unity Core 编译版本维持 1.8.0。未修改 Unity C# 工具实现；发布包保留与本版本程序配套的信任数据。

本次模块化不改变工具说明内容，不声明模型 token 用量下降。

Protocol: MCP 2.0 (`2026-07-28`). Windows binaries are not code-signed; verify the release manifest hashes.
