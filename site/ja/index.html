Booth クリエイターのための道具

アバター改変、表情 BlendShape、衣装着せ替え、マテリアル、shader optimization を支援します。lilToon、Poiyomi、その他の generic shaders は、プロジェクトの実際の機能に合わせて確認します。

表情と BlendShape

形状キーを調べ、小さな変更をプレビューして読戻しを確認します。

衣装着せ替え

衣装、パラメータ、バインド案を整理します。書き込みは Beta です。

AI × Unity MCP

外部 Agent は読み取りと計画を行い、Unity の書き込みは選択した権限モードと承認フローに従います。

顔の調整には対応する形状キーが必要です。衣装の書き込みは Beta のため、工程をバックアップして読み取りスキャンから始めましょう。内蔵 AI は Provider と API key の設定が必要です。外部 Agent は自身のモデル設定を使います。
3 ステップ

インストール → Import → 確認

App をインストール

Web Installer または Offline Installer でインストールし、App はまだ起動しません。既存の Unity プロジェクトをバックアップします。

Unity Core を Import

Unity 2022.3 LTS の VRChat SDK3 Avatar プロジェクトへ VRCForge.unitypackage を Import All し、Core Ready を待ちます。

読み取りから開始

プロジェクトと Avatar を選び、Doctor または Validation Report を実行してから小さな変更を承認します。
