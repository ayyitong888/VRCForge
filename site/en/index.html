Make lightly, verify carefully

Practical tools for creators

Check face and expression BlendShapes, plan outfits and wardrobes (Beta), inspect generic shader capabilities, and review optimization suggestions. lilToon, Poiyomi, or another shader is selected by the project’s actual capabilities.

Avatar customization

Scan shape keys, preview a small change, and inspect readback.

Outfits and wardrobes

Organize clothing, parameters, and binding plans; writes remain Beta.

AI × Unity MCP

External Agents can read and plan; Unity writes follow the selected permission mode and approval flow.

Face adjustments depend on the avatar’s available shape keys; wardrobe writes are Beta. Back up your project and start with a read-only scan. The built-in AI needs a configured Provider and API key; external Agents use their own model configuration.
Three steps

Install → import → inspect

Install the App

Install the Web or Offline Installer and keep the App closed for now. Back up your existing Unity project.

Import Unity Core

In a Unity 2022.3 LTS VRChat SDK3 Avatar project, import VRCForge.unitypackage and wait for Core Ready.

Start read-only

Choose the project and Avatar, run Doctor or Validation Report, then request a small approved change.
