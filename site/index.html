为创作者准备的实际工具

从调整细节到搭配整套造型，把重复的操作交给 AI，留更多时间给创作。

调整外形与表情

调整模型已有的脸型、身材和表情选项，一边看效果，一边改到喜欢。

搭配衣服与配饰

给模型穿上衣服、加上配饰，整理好游戏里的换装菜单。

制作换装动画

让衣服随着动画切换，为换装加入渐变、溶解等演出效果。

调整颜色与质感

修改衣服、头发和配饰的颜色、贴图与材质，让整套搭配更协调。

组合模型与部件

跟着换头和部件移植工作流，把喜欢的模型部件组合起来，并检查连接效果。

减轻模型负担

查看哪些贴图或部件占用较多资源，调整贴图大小和压缩，配合已安装的插件继续优化。

选择顺手的 AI

填入 API Key 使用内置 AI，或通过 MCP 连接你常用的 AI 助手。你可以选择逐步确认，也可以允许它自动操作。

保存常用做法

把常用操作保存成技能，下次继续用；也可以导入、导出 .vsk 技能包。

查看效果，恢复修改

查看修改后的画面和动画，保存阶段性备份；需要恢复时，选好备份并确认。

能调整的内容取决于模型本身。比如，捏脸需要模型带有脸型调节选项，部分换装和优化功能还需要配套插件。
三步连接

三步开始改模

安装 VRCForge

下载安装器并完成安装，先不要打开软件。记得备份你的 Unity 工程。

装好 Unity 插件

在你的 VRChat 模型工程里导入 VRCForge.unitypackage，等待 Unity 完成编译。

告诉 AI，你想怎么改

打开 VRCForge，选择工程和模型，连接 AI。可以先试一句：“帮我把这件衣服改成粉色。”
