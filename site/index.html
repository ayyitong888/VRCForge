轻快开始，认真验证

为创作者准备的实际工具

面向 VRChat Avatar 的 avatar editor：支持脸部与表情 BlendShape 检查、衣装与衣柜（Beta）、材质与通用 Shader 诊断，以及性能优化建议。lilToon、Poiyomi 或其他 Shader 是否适用，仍按项目能力检查。

改模与表情

扫描形态键，预览小范围调整，再查看读回结果。

衣装与换装

整理衣物、参数和绑定方案；写入功能保持 Beta。

AI × Unity MCP

外部 Agent 可读取和规划，Unity 写入遵循所选权限模式与审批流程。

脸部调整取决于 Avatar 已有的形态键，衣柜写入为 Beta；先备份工程，从只读扫描开始。内置 AI 需配置 Provider 与 API Key；外接 Agent 使用其自己的模型配置。
三步连接

安装 → 导入 → 开始检查

安装 App

下载 Web 或 Offline Installer 并安装，先不要启动 App。备份已有 Unity 工程。

导入 Unity Core

在 Unity 2022.3 LTS 的 VRChat SDK3 Avatar 工程导入 VRCForge.unitypackage，等待 Core Ready。

启动并只读开始

启动 App，选择工程和 Avatar，运行 Doctor 或 Validation Report 后再申请小范围修改。
